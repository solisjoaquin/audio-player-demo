# Demo de reproductor

HTML, CSS y JavaScript sin dependencias. Abrir `dist/index.html` en un navegador o servir `dist/` con cualquier servidor estático.

Incluye reproducción real, pausa, búsqueda por la onda con teclado o mouse, retroceso de 15 segundos, velocidad, volumen y silencio. Permite cargar audio local sin subirlo a ningún servidor. La onda es ilustrativa. La pista incluida es una pista instrumental generada de 45 segundos, no el capítulo completo.

El diseño y la portada fueron exportados del archivo Kind echo en Paper. El audio se controla con HTMLAudioElement.
